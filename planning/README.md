# 기획서

공모전 공식 접수양식(`template.docx`, 공모전 사이트 제출 안내에서 받은 「공모전 접수양식 · 개인정보 수집·이용 동의서」 1020 ver.)의
02장 입력칸(1~8번)에 기획 내용을 채워 기획서를 만든다. **이 접수양식이 곧 기획서**다.

| 파일 | 내용 |
|---|---|
| `content/1_순간기록.js` | 메인 아이템 기획 내용 (1~6번 칸) |
| `content/2_길눈.js` | 예비 아이템 |
| `build.js` | 내용을 양식에 채워 docx 생성 |
| `output/` | 생성 결과. PDF는 Word에서 내보낸 것 |

## 만들기

```bash
cd planning
npm install
npm run build        # output/1_순간기록.docx, output/2_길눈.docx
```

PDF가 필요하면 Word로 docx를 열어 PDF로 저장한다.

## 내용 쓰는 규칙

- 블록: 문자열 = 문단, `{ h }` = 소제목, `{ b }` = 글머리 항목, `{ n }` = 번호 항목, `{ t, w }` = 표(첫 행이 머리글, w는 열 너비 합 9600 안팎), `{ note }` = 회색 주석. `**굵게**`만 지원.
- `items` 배열의 순서가 양식 칸 순서다(1 한 줄 소개, 2 기획 배경, 3 주요 기능·차량 특화, 4 시나리오, 5 개발 계획, 6 기대효과, 7 참고자료, 8 숏폼). 7·8은 비워 두면 양식 그대로.
- 02장(작품 소개)에는 이름·연락처·소속을 쓰지 않는다(블라인드). 01 신청서와 03·04 동의서는 제출 전에 사람이 직접 채운다.
- 근거는 공식 자료와 공개 통계만. 다른 참가작 자료는 쓰지 않는다.
- 문체: 과장 없이 평이하게. "AI가 쓴 티" 나는 표현(과한 강조, 이모지, 상투어) 금지.
