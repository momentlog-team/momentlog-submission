# 시연 시나리오 (약 1분)

외부 업체 없이 에뮬레이터 + PC 서버만으로 진행한다.

| 시점 | 화면·소리 | 구현 |
|---|---|---|
| 0초 | 앱에서 "시연 재생" → "시연 데이터 재생 중" 표시 | `ReplaySource` |
| 0~14초 | 32km/h 주행 | 재생 데이터 |
| 13.8초 | 우측 방향지시등 켜짐 | 재생 데이터 (Virtual Console로 직접 켜도 됨, TODO) |
| 15.9초 | 브레이크 시작, 서서히 감속 | 재생 데이터 |
| 20초 | 14km/h에서 추돌, 0km/h | `HardStopDetector`가 감지 |
| 30초 | 기록 저장, 원본 봉인 → 목록에 경위 문장 표시 | `IncidentRecorder`, `SealClient` |
| (2단계) | 정차 후 "상황을 말씀해 주세요" → 진술 | TTS·STT |
| (2단계) | 사고 정리 문서 PDF + QR → 휴대폰으로 QR 확인, 숫자 하나 고친 가짜는 "원본과 다름" | server |

예상 경위 문장 (core 테스트 출력):

```
급정지가 감지되어 직전 30초와 직후 10초의 차량 기록을 저장했습니다.
급정지 6.2초 전부터 우측 방향지시등이 켜져 있었습니다.
급정지 4.1초 전부터 브레이크를 밟고 있었습니다 (그때 속도 32km/h).
급정지 직전 30초 최고 속도는 32km/h, 급정지 시점 속도는 0km/h였습니다.
급정지 시점에 핸들은 오른쪽으로 12° 돌아가 있었습니다.
```
